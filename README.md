# Веб-задачи на JavaScript

Учебные задания по дисциплине «Языки программирования» (РЭУ им. Г. В. Плеханова, 2026).
Каждая задача — отдельная страница на чистых HTML, CSS и JavaScript, без библиотек и фреймворков.

## Задача 3. Генератор вариантов заданий

Формирует варианты контрольной из списка вопросов: вопросы выбираются случайно,
при этом любые два варианта совпадают не больше чем на 50% вопросов.
Если вопросов не хватает, страница сообщает, сколько вариантов можно составить.

**Что применено:** случайная выборка (алгоритм Фишера — Йетса), перебор с повторными попытками,
динамическое построение страницы через DOM.

## Задача 4. Счётчик времени от/до даты

Поле даты со своим всплывающим календарём (выбор месяца и года, номера недель, выходные).
Под полем выводится, сколько лет, месяцев, дней, часов и минут прошло или осталось
до выбранной даты. Текст обновляется каждые 30 секунд, некорректная дата даёт сообщение об ошибке.

**Что применено:** работа с `Date`, таймеры `setInterval`, обработка событий,
проверка ввода, склонение слов по числам.

## Задача 5. Форма экзаменационной ведомости

Таблица экзаменов с добавлением и удалением строк, автоматическим расчётом оценок
и среднего балла. Список экзаменов загружается AJAX-запросом, данные отправляются
на сервер с обработкой ответов 200, 400 и 500. Номер ведомости хранится в Cookie.

**Что применено:** формы и валидация HTML5, `fetch` и промисы, Cookie,
индикация загрузки, обработка ошибок сервера.

## Как запустить

Скачать репозиторий и открыть `index.html` нужной задачи в браузере.
Для задачи 5 нужен интернет: она обращается к сервису httpbin.org.
